# Мессенджер на базе GREEN-API

Тестовое задание на должность «Фронтенд разработчик React».

Веб-приложение мессенджера с адаптивным интерфейсом для отправки и получения текстовых сообщений через GREEN-API.

## Возможности

- Подключение к GREEN-API через `idInstance` и `apiTokenInstance`
- Проверка состояния экземпляра GREEN-API
- Создание нового чата по имени и номеру телефона
- Отправка текстовых сообщений
- Получение текстовых сообщений
- Отображение списка чатов
- Отображение последнего сообщения в списке чатов
- Отображение времени сообщений
- Отображение первой буквы имени пользователя в качестве аватара
- Адаптивный интерфейс для компьютеров и мобильных устройств
- Отдельное отображение списка чатов и текущего диалога на мобильных устройствах

## Подключение GREEN-API

Для работы приложения необходимо иметь активный экземпляр GREEN-API.

На странице подключения необходимо указать:

* `idInstance`
* `apiTokenInstance`

После отправки формы приложение проверяет состояние экземпляра GREEN-API.

При успешной авторизации пользователь переходит в интерфейс мессенджера.

## Работа с чатами

Для создания нового чата необходимо указать номер телефона.

После создания чат появляется в списке чатов.

В открытом диалоге пользователь может отправлять и получать текстовые сообщения.

## Адаптивность

На десктопных устройствах список чатов отображается слева, а выбранный диалог — справа.

На мобильных устройствах список чатов и текущий диалог отображаются как отдельные экраны. После выбора чата открывается диалог, а кнопка «Назад» возвращает пользователя к списку чатов.
